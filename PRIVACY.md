# TabRest — Privacy Policy

**This file is a pointer. The policy has moved.**

Read it here:

## https://som3669.github.io/privacy-policy/tabrest/

The policy now has a single source of truth in
[som3669/privacy-policy](https://github.com/som3669/privacy-policy) —
`src/tabrest.md` there, rendered to the page above and served from GitHub Pages.

Why the split: a privacy policy URL hosted out of a product repo dies the moment
that repo goes private, and a dead policy URL is a Chrome Web Store compliance
problem rather than a broken link. The policies repo holds nothing but policies,
so it can stay public regardless of what happens here.

This stub stays in place so any existing link to this path still leads to the
policy instead of a 404. Do not paste policy text back into it — that is how the
hosted copy and the repo copy drift apart, and inconsistency between the policy,
the store dashboard disclosures and actual behaviour is itself grounds for
suspension.
